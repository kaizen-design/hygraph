# Hygraph Blog

A headless blog built with Next.js, GraphQL, and Hygraph CMS.

## What this demonstrates
- Headless CMS architecture (content modeling, GraphQL queries)
- Next.js Pages Router with SSR (getServerSideProps)
- Responsive front-end with Tailwind CSS
- Full path from design to deploy

## Stack
- Next.js
- React
- GraphQL (Hygraph API)
- Tailwind CSS

## Live Demo
[hygraph.netlify.app](https://hygraph.netlify.app/)

## Features
- Featured and recent posts
- Categories
- Markdown articles
- Author profiles
- Comments

## Running locally
1. Clone: `git clone https://github.com/kaizen-design/hygraph.git`
2. Install: `npm install`
3. Set up environment variables (Hygraph API endpoint)
4. Run: `npm run dev`
